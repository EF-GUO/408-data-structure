折半插入排序可视化

它本质上还是插入排序：前面保持有序，每次拿出一个新元素。 改进点是：用折半查找快速确定插入位置，然后再统一后移元素。

有序区 待插入 mid 后移
1. 前半部分有序

第 i 趟时，arr[0] 到 arr[i-1] 已经排好序。

2. 折半找位置

比较 temp 和 arr[mid]，不断缩小 low 与 high 的范围。

3. 后移再插入

查找结束后，low 就是插入位置，再把后面的元素整体右移。

1void BinaryInsertSort(int *arr, int length) {
2 if (arr == NULL || length <= 1) return;
3 for (int i = 1; i < length; i++) {
4 int temp = arr[i];
5 int low = 0, high = i - 1;
6 while (low <= high) {
7 int mid = (low + high) / 2;
8 if (temp < arr[mid])
9 high = mid - 1;
10 else
11 low = mid + 1;
12 }
13 for (int j = i - 1; j >= low; j--)
14 arr[j + 1] = arr[j];
15 arr[low] = temp;
16 }
17}
过程理解
折半插入排序每一趟都分为三个阶段。
1

取出待插入元素 temp

从下标 1 开始，因为单个元素天然有序。每次将 arr[i] 暂存为 temp。

2

在有序区中折半查找

设置 low = 0，high = i - 1。若 temp 小于 arr[mid]，说明位置在左边；否则在右边。

3

移动元素并插入

循环结束后 low 就是插入位置，把 low 到 i - 1 的元素向右移动一位，再把 temp 放到 arr[low]。

和直接插入排序对比
折半插入排序减少的是比较次数，不是移动次数。
项目 直接插入排序 折半插入排序
找位置 顺序比较 折半查找
比较次数 较多 较少
移动次数 可能很多 没有减少
时间复杂度 O(n²) O(n²)
稳定性 稳定 稳定
