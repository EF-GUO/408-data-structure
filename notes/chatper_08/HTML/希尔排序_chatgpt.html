8.2.3 希尔排序 Shell Sort

先“粗排”，再“细排”

希尔排序是对直接插入排序的改进：先按增量 gap 把相隔一定距离的元素分成若干组，组内做插入排序；然后逐步缩小 gap，最后 gap=1 时完成整体插入排序。

空间：O(1) 最坏：O(n²) 不稳定排序 适合基本有序 / 数据量较小

看懂它只抓 3 点

1
gap 分组例如 gap=5，则 A[0] 与 A[5] 一组，A[1] 与 A[6] 一组。
2
组内插入排序每组都让较小元素向前移动，使序列逐步接近有序。
3
gap 缩小到 1最后一趟就是普通插入排序，但此时数据已经比较有序，所以移动次数更少。

增量进度

这一页重点

  • 大 gap：让小元素快速跳到前面。
  • 小 gap：继续细调局部顺序。
  • gap=1：完成最终整体排序。
  • 相同元素可能跨组交换，所以不稳定。
C 语言实现：指针参数 + 参数检查 
void ShellSort(int *A, int n) {
    if (A == NULL || n <= 1) return;

    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; ++i) {
            int temp = A[i];
            int j = i;

            while (j >= gap && A[j - gap] > temp) {
                A[j] = A[j - gap];
                j -= gap;
            }
            A[j] = temp;
        }
    }
}
