直接插入排序：像整理扑克牌一样排序

重点只看一件事：前面已经有序，拿出当前元素，向前比较，把比它大的元素后移，最后插进去。下面的动画会一步一步展示这个过程。

知识点一眼看懂

直接插入排序的核心：始终保证左边是一段有序序列。每次从右边无序区拿出一个元素，插入到左边有序区的正确位置。

若 A[0] < A[j]：说明 A[j] 比当前元素大，需要 A[j+1] = A[j] 后移；
若 A[0] ≥ A[j]：说明插入位置找到了，把 A[0] 放到 A[j+1]。

为什么稳定？代码中比较条件是 A[0] < A[j]，相等时不会后移，所以相同关键字的相对顺序不会改变。

为什么要做参数检查？指针版函数必须先判断 A == NULL，否则访问 A[i] 可能导致程序崩溃；同时要判断 n <= 0 这种非法长度。由于本算法使用 A[0] 作为监视哨，调用时还要保证数组空间至少能访问 A[0…n]，有效数据放在 A[1…n]。

考点结论
空间复杂度O(1)，只使用监视哨和少量变量。
最好时间O(n)，初始序列已经有序，每趟只比较一次。
最坏时间O(n²)，初始序列逆序，每趟都要大量后移。
稳定性稳定，关键字相等时不改变先后顺序。
