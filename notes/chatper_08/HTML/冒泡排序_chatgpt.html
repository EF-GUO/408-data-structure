Bubble Sort 冒泡排序

相邻比较，较大值一路“冒”到后面

每一趟从左到右比较相邻两个元素，若前者大于后者就交换。完成一趟后，当前最大值会移动到本趟末尾；重复执行，直到整个序列有序。

核心比较相邻元素，逆序就交换。
特点稳定排序，原地排序。
复杂度空间 O(1)，时间平均 / 最坏 O(n²)。

可视化交互

观察重点

  • 一趟结束，最右边多一个有序元素。
  • 若某一趟没有交换，说明已经有序。
  • 适合理解排序思想，不适合大数据量。
查看简洁代码 
void BubbleSort(int *a, int n){
    if(a == NULL || n <= 1) return;
    for(int i = 0; i < n - 1; i++){
        int swapped = 0;
        for(int j = 0; j < n - 1 - i; j++){
            if(a[j] > a[j + 1]){
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
                swapped = 1;
            }
        }
        if(!swapped) break;
    }
}
