## 一、核心运行机制

冒泡排序的思想很简单：**相邻两个元素两两比较，顺序错误就交换，让较大的元素一步一步“冒”到后面。**

以从小到大排序为例：

第一趟从前往后比较：

```
if (A[j] > A[j + 1]) {
    交换 A[j] 和 A[j + 1];
}
```

每比较一次，只处理**相邻两个元素**。如果前面的数比后面的数大，就交换它们的位置。

一趟比较结束后，**当前未排序区中最大的元素一定会被交换到最后面**，就像气泡一样往后冒，所以叫“冒泡排序”。

冒泡排序可以理解为：

```
第 1 趟：把最大值放到最后
第 2 趟：把次大值放到倒数第二
第 3 趟：把第三大值放到倒数第三
……
```

所以它的核心过程就是：

```
相邻比较 → 顺序错误就交换 → 最大值逐趟后移
```



## 二、算法分析

### 1. 时间复杂度

平均和最坏时间复杂度都是：

```
O(n²)
```

如果加入标志变量 `flag`，当某一趟没有发生交换时，说明序列已经有序，可以提前结束。这样最好情况是：

```
O(n)
```

### 2. 空间复杂度和稳定性

冒泡排序只需要一个临时变量用于交换元素，因此空间复杂度是：

```
O(1)
```

它属于**原地排序算法**。

冒泡排序也是**稳定排序算法**。



## 三、总结

冒泡排序的特点可以概括为：

```
核心思想：相邻比较，大的后移
时间复杂度：最好 O(n)，平均和最坏 O(n²)
空间复杂度：O(1)
稳定性：稳定
适用场景：数据量较小，或者序列基本有序
```

它的优点是**思想简单、容易实现**；缺点是**交换次数多，效率较低**。
